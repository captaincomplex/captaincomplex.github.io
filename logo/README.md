# xpdr.aero logo files

The mark is the **Beacon**: a solid centre with three rings of dots that shrink outward.
The wordmark is set in Familjen Grotesk SemiBold (SIL Open Font License) and is converted
to outlines in the SVG files, so nothing here needs the font installed.

**The four main logos** are the lockups below: A2 (default), B2 (backup), M1 and M2 (black-and-white). Use them as they are. The dot sizes and spacing in the beacon are fixed and must stay the same everywhere (icons included): rings at radius 22 / 33 / 44 with 10 / 16 / 22 dots of radius 4.25 / 3.25 / 2.4, and a centre dot of radius 11.5, all on a 100-unit grid.

| File | Use |
|---|---|
| `xpdr-lockup-A2.svg` / `.png` | **Default.** Transparent. For dark backgrounds: yellow beacon, white `xpdr`, red full stop, yellow `aero`. |
| `xpdr-lockup-A2-on-dark.svg` / `.png` | The same with its near-black background. |
| `xpdr-lockup-B2-on-saffron.svg` / `.png` | **Backup.** Black beacon and `aero`, white `xpdr`, on saffron. |
| `xpdr-lockup-M1-black.svg` / `.png` | Black and white only: black, for light backgrounds. |
| `xpdr-lockup-M2-white.svg` / `.png` | Black and white only: white, for dark backgrounds. |
| `xpdr-mark-*.svg` | The beacon on its own, in saffron, ink, black or white. |
| `favicon.svg`, `favicon-16/32/48.png` | Tab icon: the full beacon (centre + three rings) in saffron on a dark tile, with the same dot proportions as the lockups. |
| `app-icon.svg`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` | Square app icons (the system rounds the corners): the same beacon on a dark tile. |

Colours: saffron `#f2b705`, near-black `#14110a`, ink `#1a1405`, red `#ff5a36` on dark and
`#d8381a` on saffron or light.
