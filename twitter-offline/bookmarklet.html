Set up the feed-capture bookmarklet

This one-time setup adds a bookmarklet you'll tap while browsing x.com to capture tweets, then save them as a file you import into the app.

1Install it

On a computer: drag this button to your bookmarks bar.

📥 Save Feed — Twitter Offline

On iPhone: Safari blocks pasting javascript: code into the address bar or a bookmark's URL field (an anti-phishing restriction), so bookmarklets don't install the classic way anymore. Use the Shortcuts app instead — it has a built-in action made for exactly this.

  1. One-time setting: Settings app → Safari → Advanced → turn on Allow JavaScript from Shortcuts.
  2. Open the Shortcuts app → tap + (new shortcut) → Add Action → search for and add Run JavaScript on Web Page.
  3. Tap the JavaScript box in that action and paste in the script below (tap Copy code first).
  4. Tap the shortcut's name at the top, rename it Save Feed, and make sure Show in Share Sheet is on. Tap Done.

To run it: on x.com, tap the Share icon in Safari's toolbar, find Save Feed in the share sheet, and tap it. The capture panel appears on the page.

On a Mac, the drag-to-bookmarks-bar button above still works the normal way.

2Capture your feed

  1. Open x.com and go to your Home timeline (or any timeline you want to save).
  2. Run Save Feed — on iPhone via the Share icon, on a computer via your bookmarks bar. A small panel appears in the corner.
  3. Scroll down slowly to load more tweets — the counter updates as it captures them.
  4. Tap Save & Download. A JSON file downloads (Files app on iPhone, usually the Downloads folder on desktop).

3Import it

Go back to the app's Import tab and choose the file you just downloaded. Full text, photos, and video get cached on this device for offline reading.

Go to Import →

⚠️ This uses X's internal, undocumented API by reading your browser's own responses while you scroll — it never touches your password. It's against X's Terms of Service, so it's meant for personal, occasional use, and may stop working if X changes its app.
